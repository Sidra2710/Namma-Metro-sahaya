# 🚇 Namma Metro Sahaya

Namma Metro Sahaya is a smart metro navigation Android application developed using Kotlin and Jetpack Compose. The application helps Bengaluru Metro passengers with route guidance, platform navigation, interchange assistance, visual metro guidance, and exit gate support.

## 📱 Features

- Dynamic metro route generation
- Purple Line and Green Line support
- Majestic interchange guidance
- Dynamic platform number detection
- Ticket scanning guidance
- Visual metro navigation
- Exit gate guidance
- Station-specific Exit Finder
- Fare estimation
- Bilingual support (Kannada & English)
- Offline functionality

## 🛠 Technologies Used

- Kotlin
- Jetpack Compose
- Android Studio
- Material 3
- Android SDK

## 📷 Application Modules

- Station Selection Screen
- Route Summary Screen
- Visual Guidance Workflow
- Exit Finder System
- Dynamic Platform Detection

## 🎯 Objective

The project aims to simplify Bengaluru Metro travel for first-time users, rural passengers, and non-English-speaking users through step-by-step visual navigation assistance.
